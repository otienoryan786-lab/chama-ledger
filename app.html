          Compare with an M-Pesa statement

          Paste lines from the paybill or till statement, or the M-Pesa messages, one per line. Each line needs its 10-character code. The app shows what is in the statement but not in the records, what has a different amount, and what is recorded but missing from the statement.

          How this protects the group

          Every change to the records is logged with the time and who made it. Each entry carries a fingerprint of the one before it, so an entry cannot be changed, removed or reordered without the chain breaking. A deleted payment stays in the trail forever. This makes changes visible. It cannot stop someone with access to the device, so share a checkpoint with the group regularly.

          Checkpoints

          A checkpoint is a short code that stands for the whole history so far. Send it to the group's WhatsApp after each meeting. If anyone later rewrites the past, the code will no longer match.
